## Featured projects

### Second Brain (AI agent)
A retrieval-augmented question-answering agent over the DuckDB documentation, built test-first (269 automated tests). It answers only from its sources, cites every claim, and refuses when the answer is not there: it refused every unanswerable question in evaluation. Its agent loop rewrites failed searches and improved correct answers from 10/12 to 11/12 against the baseline pipeline. Code and full results: github.com/Grace-goodluck/second_brain

### Artisaan's Crib (web app)
A marketplace that connects people with skilled professionals near them, from plumbers and tailors to tutors and photographers, across Nigeria's 36 states, free to use. Features include search and map view, bookings with an availability calendar, in-app chat, Paystack payments for service packages, and an admin dashboard with analytics and moderation. Built with Python and Flask, a PostgreSQL database and file storage on Supabase, and deployed on Vercel. Live: artisan-service-app.vercel.app · Code: github.com/Grace-goodluck/ARTISANS-
