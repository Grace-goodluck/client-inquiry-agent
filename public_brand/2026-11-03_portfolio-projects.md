# TechByGrace portfolio projects

## Second Brain (AI agent)
A retrieval-augmented question-answering agent over the DuckDB documentation. It answers only from its sources, cites every claim, and says "not found" when the answer is not in the documents; it refused every unanswerable question in evaluation. An agent loop rewrites failed searches and improved correct answers from 10 to 11 out of 12 against the baseline pipeline. Built test-first with 269 automated tests, in Python with FastAPI and the Gemini API.
Code and results: github.com/Grace-goodluck/second_brain

## Artisaan's Crib (web app)
A marketplace that connects people with skilled professionals near them across Nigeria's 36 states, free to use. Features include search and map view, bookings with an availability calendar, in-app chat, Paystack payments for service packages, and an admin dashboard with analytics and moderation. Built with Python and Flask, PostgreSQL and file storage on Supabase, and deployed on Vercel.
Live: artisan-service-app.vercel.app · Code: github.com/Grace-goodluck/ARTISANS-

## Eden & Sunset (restaurant and lounge website)
A website for a restaurant and lounge, presenting the venue, its food and drinks, and how to get in touch. Built with HTML, CSS and JavaScript.

## Music distribution platform (client project, partially built)
A platform for African artists to distribute their music to streaming services, similar to TuneCore or DistroKid. Built about halfway: a 14-table database design, a seeded database, a branded landing page and the start of the backend APIs.
