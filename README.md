# Client Inquiry Agent 🤖

An intelligent AI agent built in Python that drafts authentic client replies in your exact brand voice. It incorporates safety rails like price guards, number checks, and 10/10 evaluation standards to ensure precise, professional communication.

## Features
- **Voice Matching:** Learns and mirrors your personal brand voice from reference files.
- **Price Guard:** Automatically checks and validates pricing information to prevent costly errors.
- **Evaluation Loop:** Rates outgoing drafts on a 10/10 quality scale before approval.

## Tech Stack
- Python
- LLM Integrations / Agentic Workflows

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/Grace-goodluck/client-inquiry-agent.git
   ```
2. Configure your brand files and environment variables.
3. Run the agent:
   ```bash
   python main.py
   ```
